# v0.19.0-wip — runtime PS5 experimental

Release pública de fontes do runtime nativo experimental de KH 358/2 Days.

Inclui código, scripts, testes e documentação. Os testes Vulkan locais passam
no PC, mas a execução WSI/VideoOut e a primeira missão no PS5 ainda precisam
de validação de hardware.

Por motivos de direitos autorais, esta release **não inclui** ROM, dumps,
assets comerciais, `eboot`/FSELF/PRX, imagem exFAT ou PKG. O usuário deve
fornecer localmente os dados que tem direito de usar; consulte
[`docs/PUBLIC-RELEASE.md`](PUBLIC-RELEASE.md) e
[`docs/LOCAL-DATA-WORKFLOW.md`](LOCAL-DATA-WORKFLOW.md).
